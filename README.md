# ⚡ GigStaff — Gig Worker Platform for Event Staffing

A full-stack web application that connects part-time workers 
with event organizers who need staff for banquets, catering, 
outdoor parties, and liquor service events.

## 🛠️ Tech Stack
- **Backend:** Python, Flask
- **Database:** SQLite
- **Frontend:** HTML, CSS, Bootstrap 5, Jinja2

## ✨ Features
- Worker registration with skill selection
- Admin dashboard with search and filter
- Job posting system with date, location and pay
- Worker assignment to events
- Availability tracking
- Mobile responsive design

## 🚀 How to Run
git clone https://github.com/Jutuka-tejas/gig-staff-platform.git
cd gig-staff-platform
pip install -r requirements.txt
python app.py
Open http://localhost:5000

## 📁 Project Structure
gig_platform/
├── app.py          → Flask backend, all routes and DB logic
├── templates/      → HTML pages (Jinja2)
├── static/css/     → Custom stylesheet
└── gig_platform.db → SQLite database (auto-created)
